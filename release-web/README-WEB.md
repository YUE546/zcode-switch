# Z·SWITCH（无 WebView2 依赖版）

本包内的 `zcode-switch.exe` 默认以 **Web UI 服务模式**启动——**不创建任何窗口、
不要求安装 WebView2 运行时**，界面跑在浏览器里，后端（账号库、切换、额度、领取）
与本机桌面版完全同一套代码。

## 使用

1. 解压本包到任意目录（`dist/`、`WebView2Loader.dll` 必须与 exe 同级；
   DLL 是 windows-gnu 构建下 webview2 的动态加载器，缺失会报"缺少 WebView2Loader.dll"）。
2. 双击 `zcode-switch.exe`。
3. 浏览器会自动打开 `http://127.0.0.1:<端口>/?token=<一次性令牌>`。
   若未自动打开，访问地址在 `%USERPROFILE%\.zcode-switch\web-ui-url.txt`。

服务以**托盘常驻**方式运行：任务栏托盘的 Z·SWITCH 图标 = 「打开界面」（浏览器打开
Web UI）/「退出」。

服务只监听 127.0.0.1，token 为每次启动随机生成，勿泄露给他人
（该页面可以切换/删除本机 ZCode 账号）。

> `zcode-switch.exe --desktop` 才是传统桌面窗口模式（需要系统已装 WebView2 运行时）。
> 桌面模式与服务模式同时只能跑一个（单实例锁，后启动的会把先启动的唤到前台/开界面）。

## 与桌面模式的差异

| 功能 | 状态 |
|------|------|
| 账号保存 / 切换 / 删除 / 重命名 | 完整可用 |
| 额度展示、活动领取预览 | 完整可用 |
| OAuth 添加账号 | 浏览器新标签页登录，结果经服务端轮询自动写回（zcode:// 回调不可达属预期） |
| 加密导出 / 导入（.zsb） | 导出走浏览器下载；导入用文件选择器，前端预检后上传 |
| 活动领取的验证码 | 弹出浏览器小窗完成，链路与桌面一致 |
| 托盘 | 有（打开界面 / 退出） |
| 开机自启 | 不提供（服务模式无窗口，由桌面模式管理） |

## 环境变量

- `ZSW_SERVER_PORT`：固定端口（默认随机）
- `ZSW_NO_OPEN=1`：启动时不自动开浏览器
- `ZSW_WEB_DIST`：静态资源目录（默认找 exe/cwd 旁的 `dist/`）
- `ZCODE_SWITCH_HOME` / `ZCODE_SWITCH_DATA_ROOT`：与桌面版一致
